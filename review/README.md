# Review records

Drafts, Codex critiques, dispositions, and source checks from the revision loop, kept in the repository so any session can pick up the work. One folder per section, named by a short slug of its heading (`review/<section>/`); paper-level passes (organization, continuity, gates, referee pass) in `review/paper/<pass>/`. Typical files: `original.tex`, `context.txt`, `r1.tex`, `critique1.md`, `dispositions1.md`, `r2.tex`, `critique2.md`, `final.tex`, `close-review.md`, and the prompts and run logs.
